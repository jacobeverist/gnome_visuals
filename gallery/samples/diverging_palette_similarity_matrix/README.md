# Similarity Matrices — Diverging Palette

PeriodicCellEncoder similarity matrices rendered with a diverging colormap (emphasizes above/below median similarity). 80 images covering n=1–17 at varying `w`, each shown in two views.

**Views:**
- `Projected_to_Real_Space` — matrix axes ordered by input value
- `by_Region_Code` — matrix axes grouped by region identity
