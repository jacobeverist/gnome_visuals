# Hypergrid Transforms

Visualizations of hypergrid transformations and geometric mappings.

## Research Questions

- How do hypergrid transforms map between spaces?
- What are the geometric properties of these transformations?
- How can we visualize high-dimensional transforms?

## Experiments


### Matplotlib Plots
- `hypergrid_graphics.py` - Hypergrid geometric visualizations
- `plot_hgt_visuals.py` - Static hypergrid transform plots
- `plot_hgt_visuals2.py` - Additional transform visualizations

## Key Concepts

- **Hypergrid**: Grid structure in high-dimensional space
- **Transformations**: Mappings between different coordinate systems
- **Geometric properties**: Angles, distances, and topology preservation
