# Similarity Analysis

Analysis and visualization of similarity relationships between encoded values.

## Research Questions

- How similar are encodings of nearby input values?
- What distance metrics work best for comparing encodings?
- How does similarity degrade with input distance?
- How do different encoder parameters affect similarity patterns?

## Key Concepts

- **Self-similarity**: How similar an encoder's outputs are to each other
- **Distance metrics**: Hamming distance, Jaccard similarity, etc.
- **Similarity matrix**: Heatmap showing pairwise similarities
- **Locality**: Nearby inputs should produce similar encodings
