# Neural Networks

Visualizations of neural network structures and their integration with Gnome Code encoders.

## Research Questions

- How can discrete neurons be visualized?
- How do synapses connect encoder outputs to neurons?
- What network architectures work with Gnome Codes?

## Experiments

### Manim Animations
- `dpnn_structure.py` - Discrete Population Neural Network (DPNN) structure visualization
- `neural_network.py` - General neural network visualizations
- `tol_colors.py` - Color palette utilities for network visualizations

## Key Concepts

- **Discrete neurons**: Neurons that operate on binary population codes
- **Synapses**: Connections between encoder bins and neurons
- **Network topology**: How encoders feed into neural layers
